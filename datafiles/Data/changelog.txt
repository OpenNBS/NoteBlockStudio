Changes in v3.12.0 (2026.11.17):

New features:

* Finally! macOS and Linux support is out! macOS requires version 12.0
   or later.
* Added native macOS menus, Command-key shortcuts, trackpad scrolling, file
   and nbs:// URL handling, and fullscreen through the green title-bar
   button.
* Added macOS Quick Look previews. Select an .nbs file in Finder and press
   Space to view song information and listen with playback, seeking and
   volume controls.
* Added Linux AppImage integration with .nbs file associations, nbs://
   links, an "nbs" launcher search keyword and desktop portal file dialogs.
* Added song tabs! with separate save-format settings for each song and
   support for copying notes and custom instruments between tabs.
* Added four instruments from Minecraft 26.1: Trumpet, Exposed Trumpet,
   Weathered Trumpet and Oxidized Trumpet. Refreshed other bundled
   note-block samples to match Minecraft.
* Added Minecraft resource pack loading to replace note-block sounds,
   including support for sound paths and pitch shifts defined in
   sounds.json.
* Added reference audio using Ogg Vorbis or WAV files, with an adjustable
   offset and volume, mute, solo and mix modes, and configurable keyboard
   shortcuts.
* Added MIDI note-duration import as trails of notes, with per-part controls
   and optional tail-velocity fading with adjustable start and end
   percentages. Percussion remains single notes.
* Added Sound Stopper to stop all sounds or a selected layer range. Its
   range can update when layers are inserted or removed and move with the
   layer containing the stopper, with undo and redo support.
* Added dedicated editors for Tempo Changer and Sound Stopper, plus
   shortcuts for adding them from Instrument Settings.
* Added custom Minecraft sound-event mappings shared by data pack and
   command-block schematic and track export. Mappings can be searched,
   edited, loaded from sounds.json or an asset index, and matched
   automatically from resource packs.
* Added Sound Stopper support to data pack and command-block export, with
   configurable Minecraft sound categories. Export diagnostics report any
   accidental sound cutoffs.
* Song ZIP exports now preserve custom instruments' Minecraft sound-event
   mappings.
* Added Litematica-compatible .nbt export using the structure's exact
   dimensions, alongside Structure Block output.
* Added a unified schematic and track export format selector. Track export
   also supports 1.11-1.12 and pre-1.11 .schematic files.
* Added an option to follow song tempo and Tempo Changers in command-block
   schematic and track exports, snapped to the selected redstone timing
   grid. Track export now also offers 5 and 2.5 ticks per second.
* Added a restart function to exported data packs, a heavy core option for
   snare drums in schematic and track export, and an Extra Notes Pack
   download button in schematic export.
* Added an option to download Minecraft sounds directly from Mojang on
   Windows and Linux, extending the existing sound import assistant.
* Added an option to start playback automatically after downloading a song
   from Note Block World.
* Added custom background images and controls for background blur and
   dimming, including in Player Mode.
* Added adjustable selection transparency, mouse-wheel scroll speed and
   buttons for changing the interface scale.
* Added an experimental Liquid Glass option for context menus, tooltips and
   messages in the Fluent theme. Refreshed rounded corners, dialog
   navigation and song-tab animations.
* Expanded Unicode text display with dynamic font fallback and support for
   decomposed Hangul and Japanese kana with dakuten or handakuten. Replaced
   platform-specific fonts with open-licensed alternatives and included
   their licenses and credits.
* Increased the tempo control limit from 60 to 180 ticks per second (2700
   BPM). Updated MIDI instrument and percussion mappings, including the new
   trumpet instruments.
* Added three demo songs: Tetoris, Touhou 9 - Reach for the moon
   (Remastered), and Living Millennium.


Bugfixes and improvements:

* Moved Windows builds to 64 bit, allowing more memory for large songs, and
   moved the project to GameMaker 2022.0.3 LTS.
* Improved song saving and buffer exports with verified file replacement and
   clear errors for failed writes. Previous file contents are retained until
   the replacement is verified.
* Improved autosave and recovery backups, including selected or moved notes,
   separate recovery files for open song tabs, and validation before
   replacing or restoring backups. Restored files use unique names to avoid
   overwriting existing songs.
* Improved unsaved-work confirmation before quitting or installing an
   update. Cancelled or failed saves keep NBS open.
* Changed the Windows installer and uninstaller to preserve user-added files
   in the installation directory.
* Fixed the autosave countdown being reset unnecessarily while viewing the
   autosave settings.
* Fixed Save Options applying a format change before confirmation or
   ignoring a cancelled downgrade warning. Added checks for custom
   instrument limits and compatibility with the selected NBS format.
* Fixed pattern export marking the whole song as saved, even though only the
   selection was exported. Export failures now display a clear error.
* Added validation for empty, incomplete or invalid NBS files so failed
   opens do not crash the program or replace the open song.
* Fixed opening files with uppercase extensions such as .NBS and .MIDI.
* Fixed a crash when closing Song Properties in some cases, and a crash when
   removing a custom instrument while notes are selected.
* Fixed a crash when inverting a selection after pasting notes beyond the
   end of a song.
* Fixed layer names becoming blank or incorrect when layers are added, moved
   or removed, and solo-layer assignments changing unexpectedly when
   inserting layers.
* Fixed menus breaking when an instrument has an empty name, and improved
   context menu and submenu placement near window edges.
* Fixed buttons and checkboxes activating when a mouse press started
   elsewhere and was released over them.
* Improved Enter and Escape handling in dialogs. Enter activates the default
   action when a text field is not active; Escape dismisses an open menu
   before the dialog.
* Fixed pitched notes appearing at the wrong piano position in Drop Mode.
* Fixed zero-length playback sections interrupting playback.
* Fixed time displays, timeline labels and playback tempo in songs with
   Tempo Changers, including starting or seeking between tempo changes.
* Fixed the song duration shown in MIDI Import when importing tempo changes,
   including the duration after removing leading silence.
* The Stop button now stops ringing notes as well as playback. New notes are
   given priority when the audio channel limit is reached.
* Improved data pack output for non-ASCII descriptions and reduced
   scoreboard conflicts between packs with similar names.
* Fixed the update checker offering older versions as updates, and improved
   handling of cancelled or failed update installation.


Compatibility notes:

* The NBS format is now v6 for the new built-in instruments. Older save
   formats remain available through Save Options, subject to their
   instrument limits.
* The Note Block Pattern format is now v2. Exported patterns include the
   custom instrument definitions they use.
* Removed legacy schematic importing and branch export from the editor's
   File menu. Schematic and track export remain available.
* Only one MIDI input device can be used at a time.
* On Windows, application data now uses
   %APPDATA%\Minecraft_Note_Block_Studio\. Keep personal songs outside the
   program's bundled folders.
* Custom instrument sounds and reference audio use Ogg Vorbis or WAV files.
* Quick Look can use the user sound library on macOS 13 or later after NBS
   has been opened once. On macOS 12, previews use bundled sounds.
* On Linux, keep kdialog installed for KDE or zenity for other desktops;
   some exports also require 7zip.
